# Projeto de Aprendizado

## Objetivos Técnicos

1. Composição de Componentes: Uso de Atomic Design para criar componentes modulares e reutilizáveis.
2. Experiência do Desenvolvedor: Implementação de configurações de ambiente robustas.
3. Estilização: Uso de Tailwind CSS para um design Neo-Brutalista.

## Detalhes da Implementação

A aplicação utiliza Vite + React. A estilização é feita com Tailwind CSS v4.

## Q&A Profissional

1. Pergunta: Por que o Tailwind CSS é preferido em relação ao CSS tradicional neste fluxo?
Resposta: O Tailwind garante consistência, elimina CSS não utilizado e melhora a performance ao gerar o mínimo de CSS necessário.
